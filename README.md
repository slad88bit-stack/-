# Baby Noob — VTuber Studio

Интерактивный веб-сайт, превращающий 3D-персонажа **Baby Noob** из `baby_noob_animated.blend` в полноценную **VTuber-модель** в браузере.

## Возможности

- **Оригинальный 3D-риг из Blender (`BabyNoob_Rig`)** — сконвертирован в `public/models/baby_noob.glb` со всеми 8 костями (`Root`, `Pelvis`, `Torso`, `Head`, `Arm.L`, `Arm.R`, `Leg.L`, `Leg.R`), оригинальным бейджем `ROBLOX` на груди и всеми **5 анимациями** (`Idle`, `Walk`, `Wave`, `Dance`, `Spin`).
- **Трекинг лица через веб-камеру (MediaPipe FaceLandmarker)** — поворот/наклон головы, наклон тела, независимое моргание левым и правым глазом, взгляд, мимика и открытие рта в реальном времени прямо в браузере (с PiP-превью сетки лица и калибровкой центра).
- **Липсинк по микрофону (Web Audio API)** — живая анимация рта под голос (формантное различение гласных `А/Э` и `О/У`), 16-полосный эквалайзер и лёгкие движения головы/рук в такт речи.
- **Мгновенный интерактив без разрешений** — отслеживание взгляда и головы за курсором мыши, органичное авто-моргание, режим **«Демо-речь»** и поглаживание персонажа кликом (с сердечками и пружинной физикой!).
- **8 живых эмоций (клавиши `1`–`8`)** — Радость, Удивление, Смущение, Хайп (звёзды в глазах), Подмигивание, Злюка, Сонный, Плачет (анимированные слёзы).
- **OBS Studio и стриминг** — фоны «Тёплая студия», «Roblox Лужайка», «Ночной стрим», чистый **Хромакей Зелёный (`#00FF00`)** и **Синий (`#0000FF`)**, чистый **OBS-режим без интерфейса** (клавиша `H`), 4 пресета камеры, 4 схемы освещения и экспорт **прозрачного PNG-стикера** или `.GLB`-модели.
- **3D-аксессуары на риге** — наушники стримера с LED-подсветкой, золотая корона, тёмные очки, парящий нимб и румянец.

## Запуск локально

```bash
npm install
npm run dev
```

Для повторного экспорта модели из `baby_noob_animated.blend`:

```bash
npm run export-model
```
