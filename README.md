# Baby Noob & Guests — VTuber Studio

Интерактивный веб-сайт, превращающий 3D-персонажей **Baby Noob**, **Baby Guest** и **Modern Guest** в полноценные **VTuber-модели** в браузере с глубокой кастомизацией (**Кастомка**).

## Персонажи в студии

- **Baby Noob** (`baby_noob_animated.blend` → `public/models/baby_noob.glb`) — 5 оригинальных анимаций (`Idle`, `Walk`, `Wave`, `Dance`, `Spin`).
- **Baby Guest** (`baby_guest_animated.glb` → `public/models/baby_guest.glb`) — классический Гость в красно-чёрной кепке и 7 оригинальных анимаций (`California Girls`, `Cool Idle`, `Swagger Walk`, `Hype Salute`, `Breakdance`, `360° Frontflip`, `Turbo Sprint`).
- **Modern Guest** (`baby_modern_guest_animated.glb` → `public/models/baby_modern_guest.glb`) — современный Гость в куртке, кедах и кепке + 7 оригинальных анимаций (`California Girls`, `Chill Idle`, `Sneaker Walk`, `Parkour Vault`, `Shuffle Dance`, `360° Backflip`, `Parkour Dash`).

## Кастомка и возможности

- **Глубокая кастомизация каждого персонажа** (отдельное сохранение в `localStorage`):
  - **6 готовых скинов** (`Оригинал`, `Кибер-неон`, `Золотой VIP`, `Каваий`, `Геймер`, `Ангел`) + **Рандом 🎲**.
  - Перекраска кожи/головы, торса/куртки, рукавов/рук, штанов/джинсов, купола и козырька кепки, кроссовок и цвета LED/аксессуаров с сохранением оригинальных принтов **ROBLOX** (принты и кепку можно включать/выключать).
  - **4 стиля лица** (`Родное`, `Нуб •ᴗ•`, `Гость`, `Аниме ✨`) + настройка цвета глаз и рта.
  - **8 3D-аксессуаров на риге**: наушники стримера, кошачьи ушки, золотая корона, очки стримера (авто-посадка под линию глаз каждого персонажа), парящий нимб, бабочка-галстук, машущие мини-крылышки и постоянный румянец.
- **Трекинг лица через веб-камеру (MediaPipe FaceLandmarker)** + **липсинк по микрофону (Web Audio API)** + **отслеживание курсора** + **Демо-речь**.
- **8 живых эмоций** (`1`–`8`), поглаживание по клику / `Space`, **OBS-режим** (`H`), фоны включая **Хромакей Зелёный / Синий**, экспорт **прозрачного PNG-стикера** и `.GLB`.

## Запуск локально

```bash
npm install
npm run dev
```

Открой в браузере `http://localhost:5173`.
